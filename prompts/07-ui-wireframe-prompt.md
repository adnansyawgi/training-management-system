# UI Wireframe Prompt

## Role

You are a Senior Software Architect and UX Designer.

## Source Documents

Use:

**Requirements Analysis:**  
`Training_Management_System_Requirements_Analysis_v2.4`

**Software Design:**  
`Training_Management_System_Software_Design_Document_v1.15`

**Architecture Diagram:**  
`Training_Management_System_Architecture_Diagrams_v1.2`

**Sequence Diagrams:**  
`Training_Management_System_Sequence_Diagrams_v1.0`

## Task

Create UI Wireframes for the screens required by the approved requirements and software design.

For each screen identify:

- Screen purpose
- Actor
- Information displayed
- Input fields
- Actions
- Validation messages
- Navigation
- Related workflow

The wireframes must support the approved functionality and workflows.

Do not introduce functionality that is not supported by the approved documents.

Focus on structure and user interaction, not visual styling.

## Expected Output

Produce:

1. Screen list
2. UI wireframes
3. Brief explanation of each screen
4. Mapping to relevant requirements and workflows
5. Any Design Gaps or inconsistencies

The wireframes must be consistent with the approved requirements, software design, and sequence diagrams.
