# Architecture Diagram Prompt

## Role

You are a Senior Software Architect.

## Source Documents

Use the following confirmed documents as the authoritative sources:

**Requirements Analysis:**  
`Training_Management_System_Requirements_Analysis_v2.4`

**Software Design:**  
`Training_Management_System_Software_Design_Document_v1.15`

## Task

Create the System Architecture Diagram based strictly on the approved Requirements Analysis and Software Design documents.

### Show:

- Actors and external systems
- Major system components/modules
- Application layers
- Major data stores
- Important communication paths
- External integrations

Do not introduce functionality, components, systems, or technologies that are not supported by the approved documents.

The diagram must represent the architecture defined in the Software Design Document.

## Expected Output

Produce:

### 1. Architecture Diagram

### 2. Brief explanation of the diagram

### 3. Architecture elements and their responsibilities

### 4. Any inconsistency or missing information found in the source documents

If the documents do not provide enough information for a design element, identify it as a **Design Gap** rather than inventing it.

The resulting diagram must be suitable for inclusion in the Software Design Document.
