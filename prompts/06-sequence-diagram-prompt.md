# Sequence Diagram Prompt

## Role

You are a Senior Software Architect.

## Source Documents

Use:

**Requirements Analysis:**  
`Training_Management_System_Requirements_Analysis_v1.4`

**Software Design:**  
`<SOFTWARE_DESIGN_FILE_NAME>`

**Architecture Diagram:**  
`<ARCHITECTURE_DIAGRAM_FILE_NAME>`

## Task

Create Sequence Diagrams for the important system operations and business workflows defined in the approved documents.

For each sequence, show:

- Actor
- UI/client
- API
- Components/services
- Data store
- External systems where applicable
- Requests
- Responses
- Validations
- Important business-rule decisions

Only model interactions supported by the approved requirements and software design.

Do not invent additional system behaviour.

## Expected Output

For each important workflow:

1. Sequence Diagram
2. Scenario/use case represented
3. Brief interaction description
4. Related requirement IDs
5. Any Design Gaps or inconsistencies

The sequence diagrams must be consistent with the Architecture, ERD, APIs, and workflows already defined.
